# 自选股票助手

Chrome MV3 股票行情插件，用于查看自选股票和主要指数的实时行情与历史走势。

## 功能

- 添加、删除、排序自选股票
- 查看最新价、涨跌额、涨跌幅和更新时间
- 查看上证指数、深证成指、创业板指、纳斯达克等指数
- 查看分时、日、周、月、年 K 线
- K 线叠加 MA5、MA10、MA20 均线
- 图表底部拖动时间区间，四种 K 线默认显示最近 60 根
- 分时图显示价格、均价、成交量和成交额
- 交易时段自动刷新行情
- 行情中心查看大盘资金、行业板块、北向资金、南向资金和融资融券走势
- 支持标准模式、暗色模式和字号设置
- 支持股票配置导入、导出和文本备份

## 安装

1. 下载并解压发布包。
2. 打开 Chrome 的 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `dist` 目录。
5. 修改代码或替换构建文件后，在扩展页面点击“重新加载”。

## 开发与构建

```bash
npm install
npm run build
npm run build-zip
```

构建后的解压目录为 `dist`，压缩包生成在 `dist-zip`。开发调试可以运行：

```bash
npm run watch:dev
```

## 行情数据

插件通过 Eastmoney 行情接口获取股票和指数数据。浏览器需要能够访问 Eastmoney 相关域名；行情接口异常时，详情页会显示具体错误并提供重试按钮。

## 默认指数

- 上证指数：`1.000001`
- 深证成指：`0.399001`
- 创业板指：`0.399006`
- 纳斯达克：`100.NDX`

首页编辑状态下可以增加、删除和调整指数顺序。
